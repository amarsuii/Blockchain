How It Works

Two-tier tamper proof verification combining MySQL off-chain data and Ethereum on-chain immutability.

1. Canonical Format

Certificate fields are joined into a deterministic string (USN|ID|Course|Issuer|Date).

2. SHA-256 Hashing

A 256-bit cryptographic digest is generated. Any 1-bit data change alters this hash completely.

3. Blockchain Commit

The hash & certificate ID are stored permanently on Ethereum via Solidity Smart Contract.

4. Instant Verification

Verifiers compare newly calculated SHA-256 hash with immutable on-chain hash record.
